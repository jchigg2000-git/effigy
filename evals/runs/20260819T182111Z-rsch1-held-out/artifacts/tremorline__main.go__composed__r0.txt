// Command tremorlined serves the Ridgeline Regional Array's seismic event
// catalog and station inventory API.
//
// Everything it needs is inside this tree: the channel-metadata seed is
// ./testdata, the database is created under ./data, and the listen address is
// a literal below rather than an allocation looked up in some table living
// somewhere else. Clone the repository, run this, and it works.
//
// Five environment variables override the defaults, each read at its use
// site:
//
//	TREMORLINE_ADDR         listen address              (default :8330)
//	TREMORLINE_DB_PATH      SQLite file                 (default ./data/tremorline.db)
//	TREMORLINE_SEED_PATH    channel-metadata seed file  (default ./testdata/channel_seed.rcm)
//	TREMORLINE_ADMIN_TOKEN  token for /admin/ingest
//	TREMORLINE_CORS_ORIGINS comma-separated allow list, read by the API package
//
// The seed is loaded once, on the first boot against an empty database.
// Reloading it afterwards is a POST to /admin/ingest with the admin token,
// the only route in the service that checks anything at all.
